# Support

For help with **AXIS IDE**, please use the project's public channels:

- **Questions & discussion**: [GitHub Discussions](https://github.com/hoox-sh/axis-ide-vsce/discussions)
- **Bug reports & feature requests**: [GitHub Issues](https://github.com/hoox-sh/axis-ide-vsce/issues)

Before opening an issue, check the [AGENTS.md](./AGENTS.md) and [DESIGN.md](./DESIGN.md) docs for repo-specific constraints and architecture notes.

## Reporting security issues

Do not open public issues for security vulnerabilities. See [SECURITY.md](./SECURITY.md) for the disclosure process.
